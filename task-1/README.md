# Moja online vizitka

**Viktor Shishmarev**, krúžok: Pondelok 11:00

Stránka na školskom serveri: https://webte1.fei.stuba.sk/~xshishmarev/Z1_shishmarev/

## O webe

Osobná vizitka s piatimi podstránkami: profil, životopis, rozvrh, interaktívna fotka môjho pracoviska a mapa miest, kde ma nájdete.
Web je napísaný v čistom HTML5, CSS a JavaScripte, má svetlý aj tmavý režim a dá sa celý ovládať klávesnicou.
Jedinou knižnicou je Leaflet na stránke s mapou.
